# ポーカー勝率予測・GTOトレーニングアプリ 要件定義書(v1)

## 1. 概要

テキサスホールデムを対象とした、実戦利用と学習を兼ねたポーカーアプリ。 最終的には以下3機能を1つのアプリに統合する。

1. 勝率予測ツール:実際のプレイ中、相手の行動から勝率をリアルタイム予測(MVP対象)
2. GTOソルバー:GTOウィザードのような計算シミュレーション機能
3. GTO CPU対戦:GTOに基づくCPUとの対戦ゲーム

開発はClaude Codeに依頼する予定。

## 2. 利用シーン・目的

- 実際のポーカープレイ中に使用し、勝率を上げることが目的
- 利用端末は iPhone、片手操作 が前提
- ローカル動作(サーバー通信なし)を基本とする
- 将来的に App Store配信 も視野に入れる

## 3. 技術方針

- フロントエンド・ロジック: React Native (Expo) + TypeScript
- 役判定・モンテカルロ計算: TypeScriptで自前実装、または軽量ライブラリ(pokersolver等)を利用
- データ(レンジ表・ポジション別チャート等): アプリ内にJSONで保持、ローカル完結
- 配信: まずローカル/実機(自分のiPhone)でテスト → 将来的にApp Store申請を検討

## 4. 機能要件

### 4-1. 勝率予測ツール(MVP対象)

**入力**

- 自分のハンド、コミュニティカード(フロップ/ターン/リバー)
- テーブル人数:最大10人まで対応(可変)
- 各プレイヤーの行動履歴(レイズ/コール/フォールド等)
- 各プレイヤーのポジション

**ポジション**

- 標準的な9〜10人テーブルの区分を採用(UTG, UTG+1, MP, MP+1, HJ, CO, BTN, SB, BB)
- 人数が10人未満の場合は簡略化したポジション構成にする(例:6人ならUTG/MP/CO/BTN/SB/BB)
- ポジションごとに初期レンジ(オープンレンジ)を持たせる(一般的なGTOチャートを参考値として組み込む)

**レンジ推定ロジック**

- 各プレイヤーごとに個別の行動履歴・推定レンジを管理(配列/リスト構造で管理: {ポジション, 行動履歴, 推定レンジ, フォールド済みフラグ})
- フォールドしたプレイヤーはシミュレーション対象から除外
- 初期方針:簡易ヒューリスティック方式でレンジを絞り込む(例:レイズ→上位%レンジに圧縮、コール→中間レンジ)
- 将来的に静的レンジチャート方式(ポジション×アクションごとの事前定義チャート)へ精度向上を検討

**計算エンジン**

- 相手の推定レンジに対し、自分のハンドの勝率をモンテカルロシミュレーションで算出
- 人数が多いほど1試行の計算負荷が上がるため、人数に応じて試行回数を調整する設計を検討(例:2人なら多め、10人なら少なめ)

**出力**

- 自分の勝率(%)
- 相手の推定レンジ表示の有無は要検討

**UI要件**

- スマホ片手操作前提のため、入力の速さが最重要
- カード選択はクリック数を最小限に(ランク+スートのグリッドをワンタップで選択など)
- 各プレイヤーのアクション記録は少タップで完結
- 勝率はひと目で分かる表示(数値+簡易バー等)
- 新しいハンド開始時のリセット操作をワンクリックで
